## 🚀 Featured Projects

### [HexForge](https://github.com/ralphwarrand/HexForge)
A cross-platform C++20 engine framework built from scratch as a research surface. 
- **Tech:** C++20, OpenGL 4.x, CMake, GitHub Actions.
- **Features:** PBR (Cook-Torrance) shading, Position-Based Dynamics (cloth/fluid), custom memory allocator, Dear-ImGui editor, batched throughput.

### [MochaNES](https://github.com/ralphwarrand/MochaNES)
A cycle-accurate Nintendo Entertainment System emulator in pure Java.
- **Tech:** Java (JDK 17+), Maven.
- **Features:** Cycle-accurate 6502 CPU (including illegal opcodes), Loopy's Logic PPU rendering, and NROM/MMC1 mappers. Verified against `nestest.log`.

### SPLICED (Steam Release)
Lead AI Programmer & PR Lead for a UE5 Metroidvania shipped on Steam.
- Built a multi-phase boss encounter with spline-driven attacks, animation-notify hit registration, and data-driven tuning.
- Optimized game performance by recovering FPS through targeted profiling (e.g., batching static meshes).

### Engram
A domain-specific language for NPC behaviour featuring a source-to-source compiler emitting libGDX AI Java.
